交互说明
  1. 三步流程：①选择文件/文件夹 → ②确认与导入目标（知识库+父级文档，或小记分组）→ ③结果页；步骤条实时高亮（三个关键帧已分别绘制，见上）。
  2. 点击「开始导入」前弹出确认框，并自动对现有数据做 ZIP 备份，失败可回滚。
  3. 格式转换：docx 经 mammoth、html 经 turndown 转为 Markdown 后入库（main/import-external.ts）。
  4. 勾选「保留目录结构」时按源目录层级创建父级文档；失败项可展开原因并单独重试或跳过。
  5. 导入完成后主进程发送 menu:import-complete，渲染端刷新知识库/小记列表。
