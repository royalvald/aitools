交互说明
  1. 待办为独立数据模块（todo:* IPC），不依附于小记/文档存在；支持标题、详情（Markdown）、优先级、截止时间、关联目标。
  2. Dashboard 待办 Tab 显示未完成数徽标；面板按「今天 / 稍后 / 已完成」分组，已完成项划线灰显。
  3. 行悬停显示「编辑 / 删除」快捷操作；点复选框即时切换完成状态。
  4. 关联目标可下拉选择小记或文档，从待办可一键跳转被关联对象。
  5. 支持从白板便签「转待办」，生成待办并自动关联来源（📐 目标态：当前全链路未实现，见 IMPL_GAP §6 决策记录）。
