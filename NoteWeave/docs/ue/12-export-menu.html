交互说明
  1. 面板从「⋯」按钮右上锚定展开（约 300px 宽），点击面板外或 Esc 关闭。
  2. 选择格式后经系统 dialog 选择保存路径，再执行导出；完成后按开关自动打开所在目录。
  3. 基础多格式（PDF/HTML/Word/MD/TXT/RTF/OPML/LaTeX/EPUB）由主进程 main/doc-export.ts 承担。
  4. Pandoc 增强格式（DOCX 模板 / EPUB 带目录等）由 main/pandoc.ts 调用外部 Pandoc；未检测到时该分组替换为安装引导。
  5. 导出过程中按钮置为「导出中…」，失败时弹出错误提示并可重试。
