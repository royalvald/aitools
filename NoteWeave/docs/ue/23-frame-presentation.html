交互说明
  1. 进入后全屏播放，按白板框架（Frame）顺序分页；每页为该框架区域内容的静态缩略渲染（便签/形状/连线/手绘/内容卡片）。
  2. 方向键 ←/→、空格或点击画布左右半区切换页；圆点指示器可直接跳页。
  3. Esc 或右上「✕ 退出」退出演示，返回白板浏览态。
  4. 「⤓ 导出 PDF」由 main/wb-export.ts 承担，按框架逐页导出为 PDF 文档。
  5. 独立「展示」窗口功能已移除，演示仅在此 FramePresentation 内进行。
