交互说明
  1. 空小记标题自动存为「无标题」，空文档名自动存为「未命名文档」，不阻断创建流程。
  2. 创建成功后直接进入对应详情 / 编辑器：小记→NoteDetail，文档→KbDocEditor，待办→TodoList 高亮新条目。
  3. 「新建文档」的父级文档下拉按层级缩进展示，选中后作为子文档挂载（REQ-006）；思维导图类型进入 MindmapEditor。
  4. 「新建待办」的关联目标可选小记或文档，保存后出现在对方「关联与反链」抽屉中。
  5. 「新建分组」的父分组下拉支持多级嵌套；取消或点击遮罩直接关闭，不产生数据。
  6. 「挂载外部知识库」仅选目录 + 只读开关：挂载后以「只读」角标出现在知识库网格，编辑入口禁用；原目录结构映射为文档树。
