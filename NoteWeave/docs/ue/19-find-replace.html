交互说明
  1. Ctrl+F 唤起浮条（自动填入选中文本），Esc 关闭；阅读 / 富文本 / Markdown 三种模式行为一致。
  2. 匹配计数「N/M」实时更新；↑/↓ 或 Enter/Shift+Enter 在命中项间切换，当前项以深色描边强调。
  3. 富文本模式支持「第 N 处定位」：切换命中项时编辑区平滑滚动跳转并短暂闪烁提示。
  4. 「Aa」大小写开关与「全词」开关注入匹配逻辑（lib/find-replace.ts）；「展开替换 ▾」展开第二行替换输入。
  5. 「全部替换」弹出确认对话框（影响 N 处），确认后一次性完成并关闭确认框。
