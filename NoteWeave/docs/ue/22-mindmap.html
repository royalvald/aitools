交互说明
  1. 思维导图为独立文档类型，数据存 {docId}.mindmap.json（main/mindmap-doc.ts）；目录树中以专用图标区分（见 UE-03）。
  2. 双击节点进入行内编辑，Enter 确认；Tab 新建子节点，Enter 新建兄弟节点，Delete 删除节点（子树级联）。
  3. 支持与 Markdown 大纲互转：Markdown 标题层级 ↔ 节点层级，便于从既有文档生成脑图。
  4. 画布支持平移/缩放；「适应画布」自动缩放至全图可见，「收起/展开全部」批量折叠或展开子树。
  5. 「导出」支持 PNG 图片；右侧小面板在选中节点时可用，「↩收起」折叠该节点子树。
