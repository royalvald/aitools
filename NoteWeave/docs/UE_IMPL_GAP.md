# 织记（NoteWeave）UE ↔ 实现 差异对照报告

> 比对基准：UE 线框 `docs/ue/`（UE-01 ~ UE-24，2026-08-26 交付）+ 规范 `docs/UE_DESIGN.md` ↔ 当前实现 `src/renderer/src/**`。
> 方法：24 屏逐屏比对（6 组并行）+ 关键结论主线程抽查复核；本文仅收录高置信差异（两侧均有代码/线框证据）。
> 与 `docs/UE_COVERAGE.md` 的区别：覆盖度报告回答「需求是否有 UE」，本报告回答「UE 与实现差多远」。

## 1. 总体结论

**骨架与数据层基本就位，但新 UE 不是现状描述，而是一轮重新设计**——约 1/3 的屏（05/13/14/17/21/22/24 等）与实现存在功能级差距。差距呈四类系统性模式：

| 模式 | 说明 | 典型屏 |
|------|------|--------|
| ① 信息架构迁移未完成 | 数据入口应收进设置；多个面板要从 Modal 改抽屉/整页 | 18、16、17、10 |
| ② 实现停留在旧形态 | 整屏交互被重新设计，实现未跟进 | 13（向导）、14（多选）、21（AI 三态）、07（分组） |
| ③ 状态机未对齐 | 编辑器核心交互与 §5.1 规范不符 | 05（编辑态讨论面板、锁定弹回） |
| ④ 新字段/能力全链路缺失 | 数据模型→IPC→UI 均无 | 24（Todo 优先级/截止）、11（对话框字段）、22（导图操作） |

## 2. 全局 / 跨屏差异

1. **NavRail「数据」入口残留**（🔴 最高优先）：UE-01 / §2.1 的 NavRail 无「数据」项，数据导入导出按 UE-18 收进设置「💾 数据」分区；实现 `AppNavRail.tsx:72` 仍渲染 `DataMenuButton`，且 `SettingsDialog` 无数据/关于分区。
2. **页面级 StatusBar 缺失**：UE 骨架（§3.1）各页均有状态栏；实现 `StatusBar` 仅在 NoteDetail / KbDocEditor **编辑态**内部渲染，Dashboard / KbGrid / 回收站 / 资源管理等均无。
3. **面包屑缺上下文**：UE 要求 `工作台 / 小记 / 标题`、`知识库 / 目录… / 文档名`；实现只传单段（`NoteDetail.tsx:243`、`KbDocEditor.tsx:488`）。
4. **「✓ 完成」vs「👁 预览」**：UE / §5.1 统一「编辑→完成」文案；实现退出编辑按钮是「预览」（`DocPageHeader.tsx:122-126`）。
5. **Modal vs 抽屉/整页形态**：历史（UE：380px 右抽屉；实现：居中 Modal）、资源管理（UE：整页缩略图网格；实现：Modal 文字列表）、回收站（UE：整页；实现：Modal）。
